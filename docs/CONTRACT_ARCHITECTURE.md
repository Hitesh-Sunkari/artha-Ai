## 1. Canonical Dependency Hierarchy

The ArthaAI platform enforces a strict unidirectional dependency ladder:

```
[ Level 4: EVALUATION / RESEARCH / GOVERNANCE ]
  • evaluation/, control_plane/, evolution/
        │
        ▼
[ Level 3: BACKTEST & EXECUTION ENVIRONMENTS ]
  • backtest/ (ResearchBackend: PolarsBackend, NautilusBackend)
  • execution/ (SimulatedExecutionEngine, PaperExecutionEngine)
        │
        ▼
[ Level 2: STRATEGY LAYER (FRAMEWORK-NEUTRAL) ]
  • strategy/ (Universe, AlphaModel, PortfolioConstruction, PreTradeRisk, OrderRouter)
        │
        ▼
[ Level 1: QUANTITATIVE & DOMAIN ENGINES ]
  • data/, features/, microstructure/, options/
        │
        ▼
[ Level 0: FOUNDATIONAL CORE CONTRACTS ]
  • core/ (clock, instruments, events, market, orders, portfolio, signals)
```

### Independence Rule
The strategy layer is **strictly isolated** from:
- ❌ `fastapi`, `uvicorn`, `starlette` (Web frameworks)
- ❌ `langgraph`, `langchain`, `openai`, `anthropic` (LLM SDKs)
- ❌ `nautilus_trader`, `vectorbt`, `openbb` (External backtest/data frameworks)
- ❌ `kiteconnect`, `smartapi`, broker SDKs (Execution transport)
- ❌ `tradingview` (Charting / Webhooks)
- ❌ Direct database drivers (`psycopg2`, `redis`, `duckdb`)

## 2. Canonical Event Contracts

Every market event inherits from `MarketEvent` and provides an immutable point-in-time guarantee:

```python
class MarketEvent(BaseModel):
    event_id: str
    event_time: datetime         # Timestamp when event occurred at source (UTC)
    received_time: datetime      # Timestamp when event was received/available in system (UTC)
    source: str                  # Originating feed (e.g. 'NSE_TICK', 'REUTERS')
    instrument: Optional[Instrument]
    payload: Dict[str, Any]
    schema_version: str = "1.0.0"

    @property
    def availability_time(self) -> datetime:
        return self.received_time
```

### Point-in-Time Guarantee
A strict validator enforces:
$$\text{received\_time} \ge \text{event\_time}$$
Any event where `received_time < event_time` triggers an immediate `ValueError` to prevent look-ahead bias during historical replay.

### Event Taxonomy
- **`TradeEvent`:** Individual market prints (price, quantity, buyer/seller aggressor).
- **`QuoteEvent`:** Best bid/ask top-of-book updates.
- **`OrderBookEvent`:** Level 2 (5-depth) and Level 3 full ladder differential updates.
- **`BarEvent`:** Aggregated OHLCV candles (1m, 5m, 15m, 1D).
- **`NewsEvent`:** Unstructured corporate releases, regulatory circulars, and headlines.
- **`CorporateActionEvent`:** Stock splits, cash/stock dividends, bonus issues, rights offerings.
- **`OptionChainEvent`:** Snapshot of strikes, open interest, and implied volatilities.
- **`EconomicEvent`:** Macroeconomic metrics (RBI repo rate announcements, CPI, GDP).

## 3. The Canonical Decision Pipeline

The core trading pipeline progresses through nine strongly-typed stages:

```
[ 1. MarketEvent ]
       │
       ▼ (Aggregated by core/market/snapshot.py)
[ 2. MarketState ]
       │
       ▼ (Computed by features/ & microstructure/)
[ 3. FeatureSet ]
       │
       ▼ (Generated by strategy/alpha/)
[ 4. AlphaSignal ]
       │
       ▼ (Sized by strategy/portfolio/)
[ 5. PortfolioTarget ]
       │
       ▼ (Vetted by strategy/risk/ against MarketRuleSet)
[ 6. RiskDecision ]
       │
       ▼ (Generated by strategy/execution/)
[ 7. OrderIntent ]
       │
       ▼ (Dispatched by backtest/ or execution/ engine)
[ 8. ExecutionReport ]
       │
       ▼ (Updated by core/portfolio/position.py)
[ 9. PortfolioState ]
```

| Pipeline Stage | Contract Type | Authoritative Module Owner | Key Attributes & Guarantees |
|---|---|---|---|

## 4. Point-in-Time Availability Guarantees

In financial time series, market events and features possess two distinct timestamps:
1. **`event_time`:** The exact microsecond when an event occurred on the exchange or in the real world (e.g. an earnings report released at 16:05:00 UTC).
2. **`availability_time` (or `received_time`):** The exact microsecond when the data was received, parsed, and made accessible to the quantitative strategy (e.g. 16:05:02 UTC).

### Anti-Look-Ahead Rule
- **Backtesting Invariant:** A strategy evaluating decisions at timestamp $T$ may only consume data where:
$$\text{availability\_time} \le T$$
- Under no circumstances may bar $t$'s close price be consumed until $t + \Delta t$ has fully elapsed.
- In `FeatureSet`, if `availability_time < event_time`, the model raises an immediate exception.

## 5. Strategy & Execution Engine Contracts

### 5.1 `ResearchBackend` Contract (`src/arthaai/backtest/base.py`)
Decouples strategy research from simulation engines:
```python
class ResearchBackend(ABC):
    @abstractmethod
    async def run(
        self,
        strategy: Strategy,
        symbols: List[str],
        start_date: datetime,
        end_date: datetime,
        config: Dict[str, Any],
    ) -> BacktestArtifact:
        pass

    @abstractmethod
    def validate(self, artifact: BacktestArtifact) -> bool:
        pass

    @abstractmethod
    def metrics(self, artifact: BacktestArtifact) -> Dict[str, float]:
        pass

    @abstractmethod
    def artifacts(self, run_id: str) -> List[BacktestArtifact]:
        pass
```
Both **`PolarsBackend`** (vectorized bar screening) and **`NautilusBackend`** (tick queue simulation) implement this exact contract.

### 5.2 `ExecutionEngine` Contract (`src/arthaai/strategy/execution/base.py`)
```python
class ExecutionEngine(ABC):
    @abstractmethod
    async def submit_order(self, intent: OrderIntent) -> ExecutionReport:
        pass

    @abstractmethod
    async def cancel_order(self, order_intent_id: str) -> bool:
        pass

    @abstractmethod
    async def stream_reports(self) -> AsyncGenerator[ExecutionReport, None]:
        pass
```
- **`SimulatedExecutionEngine`:** Synthetic fill simulation with latency and slippage models.
- **`PaperExecutionEngine`:** Live market data listening with simulated matching book.
- **`LiveExecutionEngine`:** **Disabled by default in Step 0.7.**

## 6. Pre-Trade Risk & Versioned Market Rules Contract

### `RiskEngine` Interface
```python
class RiskEngine(ABC):
    @abstractmethod
    def evaluate(
        self,
        portfolio_state: PortfolioState,
        market_state: MarketState,
        signal: AlphaSignal,
        target: PortfolioTarget,
        market_rules: MarketRuleSet,
    ) -> RiskDecision:
        pass
```

### Traceability Guarantee
Every `RiskDecision` explicitly records:
- `decision_id`: Unique identifier.
- `target_id`: Originating target.
- `rule_set_id`: Specific `MarketRuleSet` applied (e.g. `SEBI_NOV_2024`).
- `rule_version`: Version string of the regulatory ruleset (e.g. `2.0`).
- `approved`: Boolean gate.
- `maximum_loss`: Hard dollar stop loss.

Every `OrderIntent` carries `originating_decision_id`, and every `ExecutionReport` carries `order_intent_id`. This creates a 100% traceable, non-repudiable audit trail from raw market event to executed broker fill.
